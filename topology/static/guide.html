guide how to use

1. Prepare this machine

  1. Edit topology/run/nestdaq.env. Set NESTDAQ to the nestdaq install directory and REDIS_SERVER to host:port. This checkout uses $HOME/nestdaq and 127.0.0.1:6379.
  2. Run ./topology/run/init.sh. It writes topology/run/redis-server.txt and starts Redis.

2. Open the viewer

  1. Run ./topology/server.sh start and open one of the printed URLs.
  2. To stop the viewer, run ./topology/server.sh stop. Redis and the device processes keep running.

After changing REDIS_SERVER, run init.sh again, then stop and start the viewer.

3. Choose xterm

On the topology page, topology only is the default, so a new run does not open xterms. Select xterm + topology before the next run script to open one per process. Changing the choice does not close windows that are already open.

4. Run the example chain

On scripts, set the directory to topology/run/example-scripts and press Enter. Run these three scripts in order:

  1. param-stf-tf-flt.sh
  2. topology-stf-tf-flt.sh
  3. run-stf-tf-flt.sh

The run script executes the parameter and topology scripts again, then starts the processes. Open topology. A box appears when a process registers in Redis.

5. Or write a small chain

  1. Open edit. Under bin/, click AmQStrTdcSampler, STFBuilder, TimeFrameBuilder, and FileSink.
  2. Set n to 2 on every service. Leave the decimator socket unlinked.
  3. Add links: AmQStrTdcSampler.out → STFBuilder.in, STFBuilder.out → TimeFrameBuilder.in, TimeFrameBuilder.out → FileSink.in.
  4. Set stem to amq2-tfb and dir to topology/run.
  5. Click write topo + param + run scripts.
  6. On scripts, open topology/run, run the new run-amq2-tfb-<time>.sh, then open topology.

6. Watch one process

On topology, click a process box.

  • That box stays outlined. Other boxes fade, and so do lines that do not touch this process. Lines that start or end here stay. When that mesh is drawn as a band, only this process's lines are drawn inside it.
  • The panel on the right shows the properties: service, state, ttl, host, and routing, then each link, then the parameters.
  • The same panel ends with the tmux screen. It keeps updating while the box stays selected. If this process has no tmux pane, the panel says so.
  • Click the same box again to clear the highlight.

A mesh is drawn as a band only when it has more links than the number in box above. That number starts at 128. Click the band to draw every line and list them on the right. Click the band again to collapse it. At or below that number the lines stay on the graph, so there is no band.

7. Control

  • Use the DAQ bar for connect, init task, run, stop, reset task, reset device, and end. Choose targets on the daq page.
  • The params page shows parameters stored in Redis.
